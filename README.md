This document presents the theoretical framework for modeling the spin period evolution of the high-mass X-ray binary SMC X-1. The calculations can be also applied to other objects. We combine observational constraints from \citet{Kahabka1999} with the accretion torque model of \citet{Dai2006} to investigate the relationship between magnetic moment, inner disk radius, and spin period derivative. The accompanying Python code implements these calculations to explore how different magnetic field strengths affect the accretion regime and predicted spin evolution.
